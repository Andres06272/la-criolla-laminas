# La Criolla · Láminas de Pantalla

Propuesta de diseño de interfaz interactiva con las 18 pantallas de la app móvil **La Criolla**, organizadas en 3 bloques de experiencia.

Cada lámina contiene la anatomía detallada de la pantalla, áreas táctiles interactivas, estados de interacción, gestos, animaciones y paleta de color.

---

2. **A2** · Crear perfil (`A2-perfil.html`)

4. **A4** · Inicio (`A4-inicio.html`)
5. **A5** · Portada Yermis (`A5-portada-yermis.html`)
6. **A6** · Portada El Mento (`A6-portada-mento.html`)

9. **B2** · Cómo jugar 1: Lanzar (`B2-como-jugar-1.html`)

11. **B4** · Reglas de la partida (`B4-reglas.html`)
